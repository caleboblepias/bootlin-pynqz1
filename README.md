# bootlin-pynqz1
Learning embedded Linux through the [Bootlin lecture materials](https://bootlin.com/doc/training/embedded-linux/embedded-linux-slides.pdf). Developing on a PYNQ-Z1 board with a Zynq-7000 SoC. Host machine is an ARM64 Linux UTM VM running Ubuntu. 

The course can be broken into the following lectures/labs:

| Lab # | Content |
|----------|----------|
| Lab 1 | Introduction and toolchain |
| Lab 2 | Boot process and bootloaders |
| Lab 3 | Kernel |
| Lab 4 | Filesystem |
| Lab 5 | Hardware |
| Lab 6 | Block filesystems |
| Lab 7 | Cross-compiling applications and libraries |
| Lab 8 | Buildroot |
| Lab 9 | Embedded Linux software stacks |
| Lab 10 | Application development and debugging |
| Lab 11 | Device driver for PL ADCS HIL |

The overarching goal is to build, end-to-end, a custom embedded Linux distribution, while understanding all tools used and the underlying architecture and mechanisms of Linux. The course will culminate in the design and testing of a device driver for the CubeSat ADCS rigid-body dynamics simulator running on the PL side of the SoC.
